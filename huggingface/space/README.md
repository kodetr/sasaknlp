# 🔬 SasakNLP: Research-Grade Bahasa Sasak NLP Toolkit

Interactive web demonstration of **SasakNLP**, an open-source NLP and morphological processing toolkit for **Bahasa Sasak** (an Austronesian low-resource language spoken by ~3 million people in Lombok, Indonesia).

Developed by **kodetr** ([kodetr.com](https://kodetr.com)).

## 🌐 Official Links
- **Website**: [https://kodetr.com](https://kodetr.com)
- **GitHub**: [https://github.com/kodetr/sasaknlp](https://github.com/kodetr/sasaknlp)
- **Hugging Face Datasets**: [https://huggingface.co/datasets/kodetr/sasak-benchmark-100k](https://huggingface.co/datasets/kodetr/sasak-benchmark-100k)

pip install sasaknlp
